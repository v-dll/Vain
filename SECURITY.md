# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems in Vain.

Report it privately through GitHub: go to the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, the steps to reproduce it, and the Vain version (`pip show vain`). You will get a reply as soon as the maintainer can manage; this is a solo project, so please be patient.

## Scope

Vain is for authorized network auditing only. Reports about misuse against networks you do not own are out of scope.
